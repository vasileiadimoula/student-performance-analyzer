# Student Performance Analyzer

A Python application for managing student grades and analyzing academic performance.

## Features

- Calculate each student's average grade
- Calculate the overall class average
- Identify the highest-performing student
- Identify the lowest-performing student
- Compare each student's performance with the class average
- Organize student data using Object-Oriented Programming (OOP)

## Technologies

- Python
- SQLite
- CSV
- Object-Oriented Programming (OOP)
- Python unittest
- Git
- GitHub

## Project Structure

- `main.py` - Runs the application and handles the main menu
- `student.py` - Contains the Student class and average calculation
- `database.py` - Handles SQLite database operations
- `test_student.py` - Contains automated unit tests
- `students.csv` - Contains the initial student data
- `README.md` - Project documentation
- `.gitignore` - Specifies files that Git should ignore
