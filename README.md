# Student Performance Analyzer

A Python application for managing student grades and analyzing academic performance.

## Features

- Calculate each student's average grade
- Calculate the overall class average
- Identify the highest-performing student
- Identify the lowest-performing student
- Compare each student's performance with the class average
- Organize student data using Object-Oriented Programming (OOP)

## Technologies

- Python
- Object-Oriented Programming (OOP)
- Git
- GitHub

## Project Structure

- `main.py` - Runs the application and performs the analysis
- `student.py` - Contains the Student class
- `README.md` - Project documentation

## How to Run

Run the application from the terminal:

```bash
python3 main.py
